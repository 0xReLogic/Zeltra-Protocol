**NOPE: Strengthening domain authentication with succinct proofs**
Zachary DeStefano, Jeff J. Ma, Joseph Bonneau, Michael Walfish

**Category:** Applications

Server authentication assures users they communicate with genuine servers via certification authorities. CAs remain weak points since any faulty CA can issue certificates for any domain. NOPE presents a new server authentication mechanism using succinct proofs, eliminating CA dependency and providing stronger domain verification security without trusted third parties.
