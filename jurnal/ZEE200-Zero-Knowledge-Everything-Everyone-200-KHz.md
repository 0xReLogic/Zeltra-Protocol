## Abstract

Zero-knowledge execution of high-level programs proceeds by repeatedly evaluating CPU steps. Each such step privately selects and evaluates an instruction (possibly involving memory access) from a rich instruction set. Building on this paradigm, ZEE (Heath et al., S&P'21) realized a full toolchain supporting arbitrary ANSI C programs, demonstrating this capability by proving SIR- and CVE-reported bugs in off-the-shelf Linux programs sed and gzip.
