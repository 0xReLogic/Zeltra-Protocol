**Morphic Accumulators and Applications: Optimal Range Proofs, Polynomial Commitments, and Ring Signatures**
Dimitrios Papadopoulos, Qiang Tang, Jiajun Xin

**Kategori:** Protokol Kriptografi

Cryptographic accumulators based on groups of unknown order (GUO) provide constant-size set membership proofs. For security, existing works require encoding set elements via division-intractable (DI) hash functions, typically instantiated as random oracles destroying algebraic structure. This confines GUO-based accumulators to purely set-membership role, making them incompatible dengan various existing cryptographic proof techniques over committed integers.
