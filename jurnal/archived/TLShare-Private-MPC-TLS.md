**TLShare: Private Authenticated MPC and FHE Inputs Over TLS**
Manuel B. Santos, Dimitris Mouris, Xiang Xie, Miguel de Vega, Andrei Lapets

**Category:** Cryptographic protocols

Transport Layer Security (TLS) is the web's backbone enabling secure client-server channels. DECO and follow-up works proved TLS response provenance without server modifications, but were limited to Boolean statements and single-client payloads. TLShare extends DECO enabling multi-client payload combinations for MPC and FHE, advancing privacy-preserving computation over authenticated web sources and enabling verifiable data fusion from multiple TLS endpoints.
