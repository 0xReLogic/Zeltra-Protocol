**Securely Scaling Autonomy: The Role of Cryptography in Future Unmanned Aircraft Systems (UAS)**
Paul Rochford, William J Buchanan, Rich Macfarlane, Madjid Tehrani

**Kategori:** Aplikasi

Desentralisasi UAS otonom memperkenalkan tantangan signifikan untuk secure communication dan consensus di lingkungan contested dan resource-constrained. Paper ini melakukan evaluasi komprehensif Messaging Layer Security (MLS) untuk group key exchange, dan threshold signatures (FROST dan BLS) untuk decentralized consensus. Tujuh library open-source terkemuka dievaluasi kinerjanya.
