**Mimblewimble Non-Interactive Transaction Scheme**
Gary Yu

**Category:** Public-key cryptography

---

## Ringkasan

Menjelaskan non-interactive transaction scheme untuk Mimblewimble protocol untuk overcome usability issue. Menggunakan Diffie-Hellman, ephemeral key shared antara sender dan receiver, public nonce R ditambahkan ke output. One-time public key P' digunakan untuk lock output ke receiver.
