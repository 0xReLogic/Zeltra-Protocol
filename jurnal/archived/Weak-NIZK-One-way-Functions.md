**On Weak NIZKs, One-way Functions and Amplification**
Suvradip Chakraborty, James Hulett, Dakshita Khurana

**Category:** Foundations

Weak NIZK arguments have soundness error ε_s and zero-knowledge error ε_zk. This paper shows that if NP is hard in worst case, existence of weak NIZK with ε_zk + sqrt(ε_s) < 1 implies one-way functions exist. The work establishes fundamental connections between weak zero-knowledge proofs and basic cryptographic primitives.
