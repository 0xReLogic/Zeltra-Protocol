**Wild McEliece Incognito**
Daniel J. Bernstein, Tanja Lange, Christiane Peters

**Kategori:** Kriptografi Kunci Publik

Wild McEliece cryptosystem uses wild Goppa codes over finite fields untuk achieve smaller public key sizes compared to original McEliece cryptosystem at same level of security against all attacks known. Namun cryptosystem drops one of confidence-inspiring shields built into original McEliece cryptosystem, namely large pool of Goppa polynomials to choose from. Paper ini shows bagaimana achieve almost all of same reduction in key size while preserving this shield.
