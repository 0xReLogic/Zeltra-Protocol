**Single-Server Private Outsourcing of zk-SNARKs**
Kasra Abbaszadeh, Hossein Hafezi, Jonathan Katz, Sarah Meiklejohn

**Category:** Cryptographic protocols

Succinct zero-knowledge arguments (zk-SNARKs) enable efficient verifiable proofs but their high proving cost is a barrier to practical deployment. This paper studies server-aided zk-SNARKs where a client/prover outsources most work to a single untrusted server while the server learns nothing about the witness or proof. The construction enables practical use of SNARKs on resource-constrained devices without trusting the computational server.
