## Abstract

Random Vector Oblivious Linear Evaluation (VOLE) correlations are a widely used backend for zero-knowledge proofs and secure computation, and can now be generated with strong concrete efficiency. Many applications, however, need correlations on the receiver's actual input. They therefore start from random VOLE and send a linear-size derandomization vector, which remains a main communication bottleneck.
