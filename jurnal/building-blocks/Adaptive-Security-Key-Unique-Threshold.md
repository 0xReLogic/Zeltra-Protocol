**On the Adaptive Security of Key-Unique Threshold Signatures**
Michele Ciampi, Elizabeth Crites, Chelsea Komlo, Mary Maller

**Kategori:** Protokol Kriptografi

Paper ini menginvestigasi asumsi security yang diperlukan untuk membuktikan adaptive security threshold signatures. Adaptive security adalah notion kuat yang memungkinkan adversary corrupt parties kapan saja selama eksekusi protokol. Memberikan dua impossibility results dan memformalkan notion key-unique threshold signature, menunjukkan keterbatasan asumsi yang diperlukan.
