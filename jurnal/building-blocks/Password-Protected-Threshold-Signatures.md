**Password-Protected Threshold Signatures**
Stefan Dziembowski, Stanislaw Jarecki, Paweł Kędzior, Hugo Krawczyk, Chan Nam Ngo, Jiayu Xu

**Kategori:** Protokol Kriptografi

Applications like cryptocurrency wallets involve users issuing signatures using private keys. To protect keys from loss or compromise, users outsource them to custodial server. This creates new point of failure karena compromise of such server leaks user's key, dan if user authentication implemented with password then password becomes open to offline dictionary attack (ODA). Paper ini presents better solution using secret-sharing.
