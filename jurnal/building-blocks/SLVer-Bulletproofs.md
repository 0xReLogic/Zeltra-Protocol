**SLVer Bullet: Straight-Line Verification for Bulletproofs**
Brandon Goodell, Rigo Salazar, Freeman Slaughter, Luke Szramowski

**Category:** Cryptographic protocols

Eagen introduced proof-of-computation over elliptic curves replacing costly group operations with efficient function field computations. This paper improves upon that framework with detailed protocol description, formal security analysis of completeness and soundness, and complexity evaluation. Applied to Schnorr and Bulletproofs protocols showing reduced computational overhead and improved practical efficiency.
