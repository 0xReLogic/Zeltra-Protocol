**WISCH: Efficient data signing via correlated signatures**
Ariel Futoransky, Ramses Fernandez, Emilio Garcia, Gabriel Larotonda, Sergio Demian Lerner

**Kategori:** Protokol Kriptografi

WISCH adalah commit-reveal protocol yang mengkombinasikan compact aggregate signatures dengan hash-based commitments untuk enable selective disclosure of correlated data di multiparty computation. Protokol memisahkan on-chain verification core dari off-chain preparation, sehingga verification cost depends only pada number of openings, bukan pada size of underlying message space.
