**Scalable zkSNARKs for Matrix Computations: A Generic Framework for Verifiable Deep Learning**
Mingshu Cong, Sherman S. M. Chow, Siu Ming Yiu, Tsz Hon Yuen

**Category:** Cryptographic protocols

Verifiable machine learning with sublinear proof sizes is now feasible but no approach achieves the trio of linear prover time, logarithmic proof and verification size, and architecture privacy. The lack of succinct neural network commitments and support for heterogeneous models leaves verification dependent on architecture knowledge. This paper presents a unified proof-composition framework achieving all three properties for scalable verifiable deep learning.
