**Zyga: Optimized Zero-Knowledge Proofs with Dynamic Public Inputs**
Tiago A. O. Alves, Vitor Py Braga

**Category:** Cryptographic protocols

Zyga is a pairing-based zero-knowledge proof system optimized for privacy-preserving DeFi applications. Its main contribution enhances existing zkSNARK constructions enabling dynamic public input substitution during verification while maintaining witness privacy through one-sided encoding. This avoids expensive G2 scalar multiplications on Solana and Ethereum, enabling practical ZK deployments on constrained blockchain environments.
