**Optimizing Backend Verification in zk-Rollup Architectures**
Mehdi Beriane, Muhammed Ali Bingol

**Category:** Cryptographic protocols

Zero-knowledge rollups are critical Ethereum scaling solutions but practical deployment faces on-chain verification cost challenges. This paper presents comprehensive implementation of the Tokamak zkEVM verifier optimized for BLS12-381 elliptic curve operations. The work details verification architecture including EVM-compatible data formatting for pairing checks, multi-scalar multiplication, and elliptic curve operations, enabling practical zk-rollup deployment.
