**3PaaS: Privacy-Preserving Post-Compromise Security as a Service**
Cas Cremers, Abhinav Nakarmi, Aleksi Peltonen, Eyal Ronen

**Category:** Cryptographic protocols

Post-Compromise Security (PCS) enables parties to recover security even after being compromised through mechanisms like the double ratchet in end-to-end messaging. However, current approaches are limited by real-world constraints and provide only partial healing effects. This paper presents 3PaaS, a service-oriented framework for achieving robust privacy-preserving post-compromise security that addresses these limitations and enables practical deployment in messaging applications.
