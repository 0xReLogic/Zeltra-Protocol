**IronDict: Transparent Dictionaries from Polynomial Commitments**
Hossein Hafezi, Alireza Shirzad, Benedikt Bünz, Joseph Bonneau

**Category:** Applications

IronDict presents a transparent dictionary construction enabling untrusted servers to maintain mutable dictionaries and provably serve lookup queries. A major challenge is supporting efficient auditing by lightweight clients. Previous solutions suffered from high server costs limiting throughput or high client verification costs hindering deployment in key transparency systems. IronDict achieves efficient server and client operations suitable for modern messaging key transparency.
