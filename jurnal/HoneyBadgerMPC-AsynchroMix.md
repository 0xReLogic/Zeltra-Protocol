**HoneyBadgerMPC and AsynchroMix: Practical AsynchronousMPC and its Application to Anonymous Communication**
Donghang Lu, Thomas Yurek, Samarth Kulshreshtha, Rahul Govind, Rahul Mahadev, Aniket Kate, Andrew Miller

**Kategori:** Protokol Kriptografi

Multiparty computation as a service (MPSaaS) is promising approach untuk building privacy-preserving communication systems. However, existing MPC implementations inadequate for this application as they do not address fairness, let alone robustness. Even single malicious server can cause protocol to abort while seeing output for itself, creating vulnerability to censorship dalam anonymous communication service.
