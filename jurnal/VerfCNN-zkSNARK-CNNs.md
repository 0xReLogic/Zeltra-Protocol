**VerfCNN: Optimal Complexity zkSNARK for Convolutional Neural Networks**
Wenjie Qu, Yanpei Guo, Yue Ying, Jiaheng Zhang

**Category:** Cryptographic protocols

As machine learning services scale, concerns about provider misconduct have emerged. Zero-knowledge proofs enable customers to verify service integrity while preserving model IP. However, existing ZKP systems for CNNs impose significant overhead. VerfCNN presents optimal complexity zkSNARKs for convolutional neural networks, achieving efficient verification of model correctness without revealing model weights or architecture details.
