# Schnorr-like Proofs of Knowledge for Hidden Oil Subspaces in UOV

**Authors:** Zhiwei Wang  
**Published:** 2026-05-21  
**Category:** Cryptographic protocols  

## Summary
A UOV public key hides a distinguished linear subspace: the public-coordinate image of the central oil-coordinate subspace. In central coordinates, the homogeneous quadratic part of each UOV polynomial contains no oil-oil monomials. Consequently, for every honestly generated UOV public key, each public homogeneous quadratic form vanishes when restricted to this hidden oil subspace.
