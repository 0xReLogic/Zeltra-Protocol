**Distributed Asynchronous Remote Key Generation**
Mark Manulis, Hugo Nartz

**Category:** Cryptographic protocols

---

## Ringkasan

Asynchronous Remote Key Generation (ARKG) adalah primitive yang enable sender generate new public key pk' untuk receiver dengan hanya receiver yang bisa compute corresponding private key sk' di kemudian hari. Key pairs indistinguishable dari freshly generated ones. ARKG dieksplorasi untuk aplikasi di WebAuthn credential dan lainnya.
