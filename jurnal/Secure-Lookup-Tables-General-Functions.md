**Secure Lookup Tables: Faster, Leaner, and More General**
Chongrong Li, Pengfei Zhu, Yun Li, Zhanpeng Guo, Jingyu Li, Yuncong Hu, Zhicong Huang, Cheng Hong

**Category:** Cryptographic protocols

Secure lookup table (LUT) protocols retrieve values from a table at secret indices for secure evaluation of non-linear functions. Most existing protocols target two-party settings with O(N) communication for table size N. MAESTRO represents state-of-the-art for three-party honest-majority settings. This paper presents improvements achieving faster and leaner constructions with more general applicability across different secure computation scenarios.
