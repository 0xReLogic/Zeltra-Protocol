**Private IP Address Inference in NAT Networks via Off-Path TCP Control-Plane Attack**
Suraj Sharma, Adityavir Singh, Mahabir Prasad Jhanwar

**Kategori:** Serangan dan Kriptanalisis

NAT widely assumed untuk conceal private IP addresses of internal clients dari off-path attackers dalam same LAN dan external observers. Paper ini shows assumption tidak hold, presenting novel off-path deanonymization attack yang infers private IP addresses of NATed clients engaged in active TCP connections dengan remote server. Attack builds on known NAT behaviors di real-world Wi-Fi routers seperti port preservation, insufficient reverse-path validation.
