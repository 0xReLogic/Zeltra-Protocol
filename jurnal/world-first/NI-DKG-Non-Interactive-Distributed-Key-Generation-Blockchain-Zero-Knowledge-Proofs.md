# NI-DKG: Non-Interactive Distributed Key Generation Using Blockchain and Zero-Knowledge Proofs

**Authors:** Alex Kampa, Pau Escrich, Marta Bellés-Muñoz, Roger Baig

**Category:** Cryptographic protocols

**Date:** 2026-03-19

**PDF:** 2026/552

## Abstract

We present a non-interactive DKG protocol that eliminates complaint procedures through the systematic use of ZK proofs. The protocol requires a timed public bulletin board with adjoined computing capacity as its coordination layer, a capability realized in practice by smart-contract-enabled blockchains.
