**Coral: Fast Succinct Non-Interactive Zero-Knowledge CFG Proofs**
Sebastian Angel, Sofía Celi, Elizabeth Margolin, Pratyush Mishra, Martin Sander, Jess Woods

**Category:** Cryptographic protocols

Coral is a system for proving in zero-knowledge that committed byte streams correspond to structured objects according to Context Free Grammars. Provers establish object validity with Coral, then selectively prove facts about objects—such as Web API response fields or JWT fields—to third parties or blockchains. Coral reduces correct parsing to simple left-child right-sibling tree checks, enabling practical structured data verification.
