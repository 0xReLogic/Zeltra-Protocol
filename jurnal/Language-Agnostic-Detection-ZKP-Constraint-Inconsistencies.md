**Language-Agnostic Detection of Computation-Constraint Inconsistencies in ZKP Programs via Value Inference**
Arman Kolozyan, Bram Vandenbogaerde, Janwillem Swalens, Lode Hoste, Stefanos Chaliasos, Coen De Roover

**Category:** Applications

Zero-knowledge proofs have matured into practical technology but implementing ZKP programs remains challenging—developers must encode both prover and verifier logic in arithmetic circuits and explicitly specify constraints. This paper presents a language-agnostic detection tool using value inference to identify computation-constraint inconsistencies in ZKP programs, reducing developer burden and improving program correctness across different ZKP languages and frameworks.
