# Beasley: Efficient Zero-Knowledge Proofs for Lattice-based Round-Optimal Oblivious Pseudorandom Functions

**Authors:** Baiyu Li, Ting-Yuan Wang, Jiapeng Zhang  
**Published:** 2026-09-13  
**Category:** Implementation  

## Summary
Verifiable oblivious pseudorandom functions (VOPRFs) enable a client to evaluate a pseudorandom function on a private input under a server-held key while verifying that the server evaluated the function honestly using its committed key. Existing practical VOPRFs rely mainly on assumptions that are vulnerable to quantum attacks.
