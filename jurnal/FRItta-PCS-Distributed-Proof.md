**FRIttata: A FRI-based Polynomial Commitment Scheme for Distributed Proof Generation**
Hua Xu, Mariana Gama, Emad Heydari Beni, Jiayi Kang

**Category:** Cryptographic protocols

This paper presents the first horizontally scalable polynomial commitment scheme that is both transparent and plausibly post-quantum secure. Combined with distributed polynomial interactive oracle proofs from Pianist, FRIttata achieves linear scalability through bivariate polynomial witness encoding. The scheme avoids trusted setup ceremonies while maintaining cryptographic security suitable for distributed proof generation.
