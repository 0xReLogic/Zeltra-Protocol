**Signatures with Flexible Public Key: Introducing Equivalence Classes for Public Keys**
Michael Backes, Lucjan Hanzlik, Kamil Kluczniak, Jonas Schneider

**Category:** Cryptographic protocols

---

## Ringkasan

Mengenalkan cryptographic primitive baru called signatures with flexible public key (SFPK). Key space dibagi menjadi equivalence classes induced by relation R. Signer bisa efficiently change key pair ke different representative dari same class, tapi without trapdoor hard untuk distinguish jika dua public keys related. Motivasinya dari structure-preserving signatures on equivalence classes (SPSEQ).
