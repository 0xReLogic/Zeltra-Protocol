**PRIVADA: Private user-centric Data Aggregation**
Betul Askin Ozdemir, Beyza Bozdemir, Ionut Groza, Melek Önen

**Kategori:** Protokol Kriptografi

Privacy-preserving data aggregation menjadi fundamental tool untuk large-scale analytics di sistem AI-driven dan cloud-based. Solusi yang ada menyediakan default privacy guarantee tapi kebanyakan assume semi-honest adversary dan gagal ensure user anonymity, selective disclosure, dan result privacy secara simultan. PRIVADA adalah maliciously secure data aggregation solution yang uses MPC untuk multiple data customers environment.
