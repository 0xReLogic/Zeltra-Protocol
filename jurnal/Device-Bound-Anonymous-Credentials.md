**Device-Bound Anonymous Credentials With(out) Trusted Hardware**
Karla Friedrichs, Franklin Harding, Anja Lehmann, Anna Lysyanskaya

**Kategori:** Protokol Kriptografi

Anonymous credentials enable unlinkable dan privacy-preserving user authentication. To ensure non-transferability among corrupt users, credentials can additionally be device-bound. Credential tied to key protected by secure element (SE), usually hardware component, dan any presentation requires fresh contribution of SE. Paper ini analyzes device binding untuk anonymous credentials dengan dan without trusted hardware.
