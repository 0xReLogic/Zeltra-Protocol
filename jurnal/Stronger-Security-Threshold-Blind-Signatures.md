**Stronger Security for Threshold Blind Signatures**
Anja Lehmann, Phillip Nazarian, Cavit Özbay

**Kategori:** Kriptografi Kunci Publik

Blind signatures memungkinkan user mendapatkan signature dari issuer secara privacy-preserving: issuer tidak belajar signed message dan tidak bisa link signature ke issuance. Threshold version membagi secret key di antara n issuers dan membutuhkan user mendapatkan minimal t ≤ n signature shares untuk derive final signature. Security seharusnya hold selama at most t-1 issuers corrupt.
