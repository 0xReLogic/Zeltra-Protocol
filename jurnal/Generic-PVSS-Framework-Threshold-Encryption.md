**Generic PVSS Framework with O(1) Complexity Using CCA2-Secure Threshold Encryption**
Liang Zhang, Dongliang Cai, Yiwen Gao, Haibin Kan, Jiheng Zhang, Moti Yung

**Category:** Cryptographic protocols

Existing PVSS schemes suffer from O(n) online complexity due to individual encryption and verification of each share. This paper presents a generic PVSS framework achieving O(1) complexity for share distribution and public verification by establishing a novel connection between PVSS and CCA2-Secure threshold encryption (CCATE). The framework enables public verifiable secret sharing with dramatically improved efficiency suitable for large-scale applications.
