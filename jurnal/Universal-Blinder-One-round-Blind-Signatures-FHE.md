# A Universal Blinder: One-round Blind Signatures from FHE

**Authors:** Dan Boneh, Jaehyung Kim

**Category:** Public-key cryptography

**Date:** 2026-03-02

**PDF:** 2026/574

## Abstract

We construct compilers that convert any secure signature scheme into a single-round blind signature scheme. An important property of the construction is that the final blind signature has exactly the same format as the underlying signature scheme, making the blind signature scheme backwards compatible with the underlying scheme.
