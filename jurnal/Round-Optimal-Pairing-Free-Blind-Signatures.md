# Round-Optimal Pairing-Free Blind Signatures

**Authors:** Julia Kastner, Stefano Tessaro, Greg Zaverucha

**Category:** Public-key cryptography

**Date:** 2026-01-17

**PDF:** 2026/091

## Abstract

We present the first practical, round-optimal blind signatures in pairing-free groups. We build on the Fischlin paradigm (EUROCRYPT 2007) where a first signature is computed on a commitment to the message and the final signature is a zero-knowledge proof of the first signature.
