**Fast AVX-512 Implementation of the Optimal Ate Pairing on BLS12-381**
Hao Cheng, Georgios Fotiadis, Johann Großschädel, Daniel Page

**Category:** Implementation

Non-degenerate bilinear maps (pairings) enable short signatures, zero-knowledge proofs, and remote attestation. Computing optimal ate pairing on BLS12-381 at 128-bit security is costly due to Miller loop and final exponentiation. This paper presents AVX-512 optimized implementation achieving state-of-the-art performance for pairing computations at BLS12-381 security level.
