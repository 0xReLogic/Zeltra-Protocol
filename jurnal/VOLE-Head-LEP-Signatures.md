**VOLE-in-the-Head Signatures Based on the Linear Code Equivalence Problem**
Michele Battagliola, Laura Mattiuz, Alessio Meneghetti

**Category:** Cryptographic protocols

Vector Oblivious Linear Evaluation in the Head (VOLEitH) is a versatile tool for designing zero-knowledge proofs and signatures in post-quantum cryptography. This paper proposes VOLE-friendly modellings for Proofs of Knowledge of solutions to Linear Code Equivalence Problem instances. Two new reductions from LEP to the Multivariate Quadratic problem are provided with independent interest for post-quantum signature design.
