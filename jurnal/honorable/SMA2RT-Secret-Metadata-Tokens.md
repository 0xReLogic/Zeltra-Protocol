**SMA2RT: Secret-Metadata Attribute-based Anonymous Rate-limited Tokens**
Anna Lysyanskaya, Eileen Nolan

**Kategori:** Protokol Kriptografi

Di online services volume tinggi seperti privacy-preserving CAPTCHA bypass atau metered paywalls, service providers harus filter malicious traffic tanpa compromise user privacy. Anonymous tokens with private metadata (ATPM) addresses ini dengan embedding hidden bit into user's token, misalnya menunjukkan apakah user suspected bot. Existing ATPM constructions limited by high communication complexity.
