**Obscura: Privacy-Preserving Protocol for the Algorand Blockchain Using LSAG Ring Signatures**
Navid Azimi

**Kategori:** Protokol Kriptografi

While public blockchains provide transparent dan auditable transaction histories, they inherently compromise user privacy. Existing privacy-enhancing protocols typically rely on zk-SNARKs to obscure transaction graph. However, implementing comparable cryptographic guarantees on high-throughput blockchains like Algorand is challenging due to strict per-call execution budgets dan state contention introduced by global shared randomness.
