**Architecture-private Zero-knowledge Proof of Neural Networks**
Yanpei Guo, Zhanpeng Guo, Wenjie Qu, Jiaheng Zhang

**Category:** Applications

A zero-knowledge proof of machine learning (zkML) enables a party to prove correct execution of a committed model using public input without revealing model information. An ideal zkML scheme should conceal both model architecture and parameters, yet existing approaches primarily focus on hiding parameters while revealing architecture. This paper addresses architecture-private zkML for neural networks, enabling parties to prove model correctness without exposing architectural details or parameters.
