**Toward Verifiable Privacy in Decentralized Identity: A Formal Framework for Minimal Disclosure and Unlinkability**
Yu Zhang, Zongbin Wang

**Kategori:** Aplikasi

Paper ini menyajikan formal framework untuk decentralized identity (DID) yang achieves both minimal disclosure dan session unlinkability under public verifiability. Diinstantiasikan sebagai PrivDID dimana user bisa prove predicate tentang committed attribute via single ring signature, thereby hiding in anonymity set dynamically selected dari public ledger. PrivDID builds on Pedersen commitments dan binary-range encodings.
