**SoK: BitVM with Succinct On-Chain Cost**
Weikeng Chen

**Category:** Cryptographic protocols

This Systematization of Knowledge covers BitVM with succinct on-chain cost, comparing approaches using different cryptographic primitives: Minicrypt privacy-free garbled circuits, homomorphic message authentication codes implying succinct garbled circuits, and attribute-based laconic function evaluation enabling reusable garbled circuits. Malicious security compilers include cut-and-choose, NIZK, and fraud proofs on checksums.
