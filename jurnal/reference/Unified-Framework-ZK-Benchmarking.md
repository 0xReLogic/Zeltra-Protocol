**A Unified Framework for Contract-Validated Benchmarking of Zero-Knowledge Proving Systems**
Matej Hulek, Martin Peresini, Ivan Homoliak

**Category:** Applications

## Ringkasan

Zero-knowledge proofs adalah operational infrastructure untuk rollups, private payments, verifiable execution, dan zkVM applications. Paper ini presents unified host-agent framework untuk benchmarking heterogeneous proving systems under common workload.
