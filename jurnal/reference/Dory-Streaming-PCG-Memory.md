**Dory: Streaming PCG with Small Memory**
Xiaojie Guo, Hanlin Liu, Zhicong Huang, Hongrui Cui, Wenhao Zhang, Cheng Hong, Xiao Wang, Kang Yang, Yu Yu

**Category:** Cryptographic protocols

Pseudorandom correlation generators generate correlated randomness for secure computation but existing PCGs are memory-consuming and unfriendly to resource-constrained devices. Even moderate devices find large memory requirements disadvantageous for ZKPs or large-scale MPC. Dory proposes a malicious streaming PCG generating bounded randomness with minimal memory overhead, enabling secure computation on resource-limited devices while maintaining strong security.
