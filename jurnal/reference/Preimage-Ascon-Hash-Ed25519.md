**Preimage-type Attacks for Reduced Ascon-Hash: Application to Ed25519**
Marcel Nageler, Lorenz Schmid, Maria Eichlseder

**Category:** Attacks and cryptanalysis

Hash functions are fundamental for commitments, signatures, and zero-knowledge proofs. This paper analyzes binding security when Ascon-Hash256 or Ed25519's EdDSA use commitments. Preimage-type attacks on reduced Ascon variants reveal vulnerabilities affecting security of constructions relying on these primitives for binding properties.
