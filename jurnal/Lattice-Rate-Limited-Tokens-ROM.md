# Lattice-Based Rate-Limited Tokens in the Random Oracle Model

**Authors:** Victor Youdom Kemmoe, Anna Lysyanskaya, Ngoc Khanh Nguyen  
**Published:** 2026-08-08  
**Category:** Cryptographic protocols  

## Summary
An anonymous credential allows a user to prove that she is authorized in an anonymous and unlinkable fashion. A rate-limited token is an anonymous credential that can only be used a limited number of times in any particular context; this means that even though we do not know which users are gaining access to a resource, there is a limit to how many resources one user may consume.
